### Added
- Settings > Accounts and sources > Plugins and integrations can set up the provider host: a small app droidtop makes
  and signs for itself on your device, which will hold root, Shizuku and wireless debugging access so droidtop itself
  holds none. Android asks you once to install it, and it waits for your approval in Plugins like any plugin. Later
  versions come with droidtop and update it without asking where Android allows that.
