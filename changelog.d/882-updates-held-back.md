### Fixed
- Updates now says when a plugin has a newer version that droidtop won't install for you, and why: for example, it's
  signed with a different key than the one you trusted. Before, it just showed no plugin updates.
- Updates now says when a plugin catalog you added can't be checked, so its plugins' newest versions may be missing.
- When a plugin catalog changes its signing key, Updates and the Plugins list now show the plugins with a newer version
  waiting there and point you to the catalog's page to review the new key. Before, those updates simply weren't shown.
