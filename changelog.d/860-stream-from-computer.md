### Added
- A game a paired computer has now lists "Stream from <computer>" in its menu's Play part. It starts the game on that
  computer and shows its window here, with its sound, and your controls play it. No PIN is asked: pairing with the
  computer is enough. The computer needs an up-to-date droidtop-agent on Windows, set to let this device start games.

### Changed
- Opening one of a computer's games in the library now streams it from that computer, Steam games included.
- When a computer has not allowed this device to start games, the message now names the right place in
  droidtop-agent: Settings, Offered, Starting games here.
