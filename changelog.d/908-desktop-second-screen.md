### Added
- Desktop can now use a second screen too: the first time the desktop runs with another screen connected, droidtop
  asks once whether the desktop extends to it or the screen keeps the companion. The answer is remembered for that
  screen, and Settings > Displays changes it.
- With the desktop on two screens, each screen's bar now lists the windows on that screen. A window's menu, and the
  windows list (Y), move it to the other screen with "Move to" and the screen's name.
