### Added
- Linking a game to a source, or searching one, starts from the folder name but lets you type your own search
  text.
- Picking a build to download opens the list of its hosts, with "Try in order" first, so you can choose one host
  yourself.
- When a mirror gives nothing, droidtop moves on to the next one, and a download it can't fetch offers Open thread
  so you can start it from the page.
- The game page has an Offline row saying whether the game plays with no network, and shows platforms, languages
  and content notes from the game's source.
- A download names the build it came from, and downloads are grouped the same way on every page.

### Changed
- The Quick Menu opens on the same tab every time.
- The companion screen shows droidtop's own clock, network and battery, its Apps tab lists the Linux desktop's
  windows, and Quit on the Now card asks first.
- Games remember their own overlay level and companion brightness.
- Update checks follow your download network rule.
- The Windows game runtime's parts are now built and hosted by droidtop itself.
- Mobile mode's menus use the same menus as the rest of droidtop.

### Fixed
- A GoFile folder too big for the download is refused with a reason instead of failing partway.
