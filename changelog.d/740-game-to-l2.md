### Changed
- What you can do with the running game is now in L2, not R2. In Gaming, L2 or a long press on that game, coming
  back to Gaming while it runs, and HOME + L2 over it all open the same menu. It has Resume, Pause, Emulator,
  Mouse mode, Controls, Report a problem, Guides, the console's search, Game options, Quit, Restart and Kill.
  R2's Quick Menu keeps only what is not about one game, and the companion's Game page keeps every row.
