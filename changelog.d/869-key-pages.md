### Changed
- The pages for setting up a key (TorBox, Real-Debrid, ScreenScraper, IGDB, SteamGridDB, TheGamesDB,
  RetroAchievements, PixelDrain and GoFile) are now ordinary Settings pages: the same top bar, rows, buttons and
  controller hints as the rest of Settings. The status is a row, each field is a text row with Paste in its
  dialog, the how-to is a short hint under the row it belongs to, and Clear asks first.
- Real-Debrid's sign-in with a code shows the code and the time left on its row while it waits.
