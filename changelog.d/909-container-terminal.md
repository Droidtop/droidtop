### Added
- A container's page has a terminal that opens on this screen, with or without Desktop running: Terminal while
  Desktop is off, Terminal here while it is up (Terminal still opens a window on the desktop then). Type with the
  on-screen or a hardware keyboard; on a controller the D-pad is the arrow keys, A is Enter, X shows the keyboard and
  B closes. Editors, top and Ctrl+C work, and turning the screen resizes it. Closing it ends the shell.
